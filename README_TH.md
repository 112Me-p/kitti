# KITTI / กิตติฯ — Interactive 3D Showroom (Draft 02 — แก้ปัญหาเสื้อแยกส่วน)

## สิ่งที่แก้จาก Draft 01

Draft 01 โหลด `Beige-Graphic-T-Shirt.glb` แล้วโมเดลแสดงเหมือนแยกเป็นชิ้น/หันผิดแกน พร้อมช่องว่างจากไม้แขวน ใน Draft 02 นี้ **ไม่ใช้ GLB เดิมในฉากโชว์** แต่สร้างตัวเสื้อ **3D Geometry จริงด้วย Three.js** ใหม่ให้มีลำตัวด้านหน้าและหลัง แขนเสื้อ 2 ข้าง รอยพับและความหนา ใส่ไม้แขวนบนราวที่กำหนดจุดสัมผัสไว้โดยตรง เพื่อให้ไม่เกิดโมเดลชิ้นส่วนลอยซ้อนเหมือนเดิม

ลายสกรีนแต่ละสีด้านหน้าและหลังสร้างเป็นภาพโปร่งใสจาก **รูปสินค้าต้นฉบับ 3 ภาพ** โดยวางบนพื้นผิวเสื้อ 3D ที่โค้งตามผ้า ภาพลายสกรีนมีข้อจำกัดความคมชัดตามต้นฉบับ และทรงเสื้อ/รอยพับเป็นการจำลอง ไม่ใช่ไฟล์ CAD/แพตเทิร์นเสื้อจริง

> หมายเหตุ: **GLB เดิมไม่ได้ถูกซ่อมโครงสร้างภายใน** แต่ถอดออกจากระบบโชว์และแทนด้วยโมเดล 3D ใหม่เพื่อแก้ปัญหาที่เกิดบนเว็บ เรายังเก็บ GLB เดิมไว้จากไฟล์ที่คุณส่งมาและ Draft 01 สำหรับการตรวจแก้ในโปรแกรม 3D ภายหลังได้

## วิธีเปิดดู

1. แตก `KITTI_3D_Showroom_Draft02.zip` ทั้งโฟลเดอร์
2. เปิดโฟลเดอร์ด้วย VS Code และ **Live Server** หรือเปิด Terminal แล้วใช้ `python3 -m http.server 8000`
3. เข้า `http://localhost:8000` บนเบราว์เซอร์ หรืออัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages
4. ต้องต่ออินเทอร์เน็ตเพื่อโหลด **Three.js** ผ่าน jsDelivr CDN (และฟอนต์ Google)
5. เลือกเสื้อจากราว 3D หรือปุ่มสี, คลิกเสื้อเพื่อเลือก, ลากซ้าย/ขวาเพื่อหมุน 360°, เลือกไซซ์/จำนวน, เพิ่มตะกร้า แล้วส่งข้อความเข้า LINE OA
6. ถ้าเครื่องไม่รองรับ WebGL หรือโหลดไลบรารีไม่สำเร็จ เว็บจะสลับเป็นภาพสินค้า 2D และระบบเลือกซื้อยังใช้ได้

**ตรวจภาพจริงก่อนเปิดรับออเดอร์:** แนะนำทดสอบบน Chrome/Edge/Safari ทั้งมือถือและเดสก์ท็อป, หมุนเสื้อด้านหน้า/หลัง ตรวจลาย, แล้วทดสอบ LINE OA `@kitti` ด้วยคำสั่งซื้อทดลองก่อนเปิดขาย

## ระบบสินค้า

- สี: BEIGE / WHITE / BLACK
- ไซซ์และราคา:

| SIZE | รอบอก (นิ้ว) | ความยาว (นิ้ว) | ราคา |
|---|---:|---:|---:|
| S | 40 | 26.5 | 390 บาท |
| M | 44 | 27.5 | 390 บาท |
| L | 48 | 29.5 | 420 บาท |
| XL | 52 | 30.5 | 450 บาท |

- ค่าจัดส่ง: 50 บาทต่อออเดอร์ ไม่ว่ามีเสื้อกี่ตัว
- เสื้อพรีออเดอร์จำนวนจำกัด 50 ตัว **ไม่มีตัวนับสต็อกอัตโนมัติ** แอดมินปิดรับเอง
- การชำระเงิน: สนทนาและแจ้งชำระทาง LINE OA
- ตะกร้าเก็บใน localStorage เฉพาะสี ไซซ์ และจำนวน ไม่เก็บชื่อ/เบอร์/ที่อยู่ถาวร

## LINE OA @kitti

- มือถือ: เปิดหน้าแชทกับ `@kitti` พร้อมข้อความออเดอร์ที่สร้างจากตะกร้า ลูกค้า **ต้องกดส่งเอง**
- เดสก์ท็อป: เว็บเปิดหน้าข้อมูล LINE OA และคัดลอกข้อความ ให้ลูกค้านำไปวางในแชทและกดส่ง
- ต้องตรวจว่า `@kitti` เป็นบัญชีของร้านจริงก่อนเผยแพร่
- เว็บไซต์ **ไม่มีระบบชำระเงินและไม่ยืนยันออเดอร์อัตโนมัติ**

## วิธีปิดรับพรีออเดอร์

เปิด `config.js` และเปลี่ยน `STORE_STATUS` จาก `OPEN` เป็น `PAUSED` หรือ `SOLD_OUT` จากนั้นเผยแพร่ไฟล์ที่แก้ไปที่ GitHub Pages

```js
window.KITTI_CONFIG={
  LINE_OA_ID:'@kitti',
  STORE_STATUS:'OPEN',   // OPEN | PAUSED | SOLD_OUT
  SHIPPING_THB:50,
  LIMIT_DESCRIPTION:50
};
```

## ขอบเขตการทดสอบ

- ตรวจความถูกต้องของไฟล์ทุกไฟล์, ไวยากรณ์ JavaScript และข้อมูลราคาแล้ว
