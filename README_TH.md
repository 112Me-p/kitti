# KITTI / กิตติฯ — Interactive 3D Showroom (Draft 01)

เว็บไซต์ต้นแบบพรีออเดอร์เสื้อวงรุ่นแรก ราวแขวน 3D ใช้โมเดลจริงจากไฟล์ `Beige-Graphic-T-Shirt.glb` ที่ให้มา

## วิธีทดลอง

1. แตก ZIP **ทั้งโฟลเดอร์** (อย่าแยกเฉพาะ HTML เพราะไฟล์โมเดลและ texture ต้องอยู่ใน `assets/`)
2. เปิดโฟลเดอร์ด้วย Visual Studio Code และใช้ Live Server หรือเปิด Terminal ในโฟลเดอร์แล้วรัน `python3 -m http.server 8000` จากนั้นเข้า `http://localhost:8000` ด้วย Chrome / Safari / Edge
3. ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Three.js จาก jsDelivr (ตอนพัฒนาใช้เวอร์ชัน `0.164.1`) และ Google Fonts โมเดล GLB/ภาพ/texture รวมอยู่ใน ZIP แล้ว
4. บนเว็บ ลอง **คลิกเสื้อบนราว** → เลือกสี → ใช้นิ้วหรือเมาส์ลากเพื่อหมุนเสื้อ → เลือกไซซ์/จำนวน → Add to Bag → กรอกข้อมูล → LINE
5. สามารถอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง GitHub repository แล้วเปิด GitHub Pages ได้

## การใช้สินค้าจริง

- สีเบจ: ใช้ **ไฟล์ GLB จริงที่คุณให้มา** (พร้อมพื้นผิวและลายสกรีน)
- สีขาวและดำ: ใช้ **โครงเสื้อ GLB เดียวกัน** แต่สร้าง texture จำลองจากโมเดลสีเบจ เพื่อให้ทดลองระบบเลือกสี 3D ได้ก่อน ยังไม่ใช่โมเดลสินค้าจริงแยกแต่ละสี
- ภาพด้านหน้า/หลังที่มาจากไฟล์อ้างอิงถูกจัดเก็บเป็นภาพประกอบและภาพสำรองเวลา 3D ไม่พร้อม
- โมเดล GLB มีความละเอียดค่อนข้างสูง อาจโหลดช้าบนมือถือรุ่นเก่า และยังไม่ได้ทดสอบประสิทธิภาพบนอุปกรณ์จริงทุกประเภท

## เชื่อม LINE OA

- ค่าเริ่มต้น LINE OA ID ใน `config.js` คือ `@kitti`
- บน **มือถือ** กดปุ่มสั่งซื้อแล้วเปิด LINE OA พร้อมข้อความออเดอร์ที่เตรียมไว้ ให้ลูกค้า **กดส่งอีกครั้ง**
- บน **คอมพิวเตอร์** เนื่องจาก LINE URL Scheme ไม่รองรับแอป LINE Desktop โดยตรง ระบบจะคัดลอกข้อความออเดอร์แล้วเปิดหน้า LINE OA ให้ลูกค้าวางข้อความและกดส่งเอง
- **เว็บไซต์ไม่ได้ยืนยันออเดอร์ รับชำระเงิน หรือส่งข้อความถึง OA โดยอัตโนมัติ** แอดมินยืนยันสต็อกและการชำระเงินทาง LINE
- ควรทดสอบบัญชี LINE OA `@kitti` เป็นบัญชีที่ถูกต้องและเปิดรับแชทจริง ก่อนเผยแพร่

## ควบคุมสถานะพรีออเดอร์

แก้บรรทัด `STORE_STATUS` ใน `config.js` จาก `OPEN` เป็น `PAUSED` หรือ `SOLD_OUT` แล้วอัปโหลดไฟล์ใหม่ขึ้น GitHub Pages:

```js
window.KITTI_CONFIG={
  LINE_OA_ID:'@kitti',
  STORE_STATUS:'OPEN', // OPEN / PAUSED / SOLD_OUT
  SHIPPING_THB:50,
  LIMIT_DESCRIPTION:50,
  MODEL_GLB:'assets/Beige-Graphic-T-Shirt.glb'
};
```

**ไม่มีระบบนับสินค้าคงเหลือแบบเรียลไทม์** จำนวน 50 ตัวเป็นข้อความจำนวนจำกัด ไม่ใช่สถานะสต็อกอัตโนมัติ แอดมินต้องปิดรับเองเมื่อครบจำนวน

## ขอบเขตเวอร์ชันทดลอง

- ระบบ 3D ใช้ Three.js/GLTFLoader + MeshoptDecoder โหลดไฟล์ GLB จริง มีโมเดลราวเหล็กและไม้แขวนสามมิติ
- คลิกเลือกสี ดึงตัวที่เลือกมาด้านหน้า หมุนด้วยการลาก รีเซ็ตมุม และใช้ปุ่มเปลี่ยนตัว
- เลือกสี/ไซซ์/จำนวน ตะกร้าหลายรายการ ราคาเปลี่ยนตามไซซ์ ค่าส่งครั้งเดียว
- `localStorage` เก็บเพียงรายการสินค้าในตะกร้า ชื่อ เบอร์ และที่อยู่ที่กรอกจะไม่ถูกบันทึกถาวรจากโค้ดเว็บไซต์นี้
- รองรับหน้าจอมือถือและมีภาพสำรองเมื่อเครื่องใช้ 3D ไม่ได้
- โปรโตไทป์นี้ยังไม่ได้รับรองความถูกต้องของรูปร่างทุกมุมของโมเดลที่นำเข้าหรือผลการเรนเดอร์จากอุปกรณ์จริง; ควรดูการแสดงผลและปรับมุม/texture ก่อนเผยแพร่จริง
